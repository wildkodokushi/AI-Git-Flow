# AI Git Flow

Скрипт для PowerShell, который автоматизирует рутину вокруг Git: создаёт ветку, раскладывает изменения по логичным коммитам в формате [Conventional Commits](https://www.conventionalcommits.org/), отправляет ветку на сервер и создаёт pull request. Тексты пишет GigaChat API.

## Как это работает

Работа разделена между кодом и нейросетью:

- **Группировка файлов детерминированная.** Скрипт сам определяет тип каждого файла (зависимости, конфигурация, CI, стили, тесты, документация, ресурсы, исходный код) и собирает группы по правилам. Исходный код делится по каталогам верхнего уровня. Нейросеть не решает, какие файлы объединять, поэтому результат воспроизводим.
- **Нейросеть пишет только текст.** Для каждой группы модель получает список файлов и сокращённый diff и возвращает одну строку с темой коммита. Для pull request модель формирует заголовок и краткое описание.
- **Скрипт всегда отрабатывает.** Если API недоступен, для группы подставляется шаблонное сообщение, и работа продолжается.

Последовательность: анализ, план, подтверждение, ветка, коммиты, push, pull request.

## Требования

- Windows, PowerShell 5.1 или новее
- [Git](https://git-scm.com/)
- Ключ авторизации GigaChat API (личный кабинет разработчика Сбера, scope `GIGACHAT_API_PERS`)
- Опционально: [GitHub CLI](https://cli.github.com/) для автоматического создания pull request (`gh auth login`)

## Установка

1. Положите `ai-flow.ps1` в удобное место, например `C:\Tools\ai-flow\`.
2. Сохраните ключ авторизации в переменную окружения пользователя (после этого откройте новый терминал):

   ```powershell
   [Environment]::SetEnvironmentVariable('GIGACHAT_AUTH_KEY', '<ваш ключ>', 'User')
   ```

   Если переменная не задана, скрипт запросит ключ при запуске. Не добавляйте ключ в репозиторий.
3. Разрешите запуск скрипта в текущей сессии:

   ```powershell
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   ```

### Сертификат НУЦ Минцифры

Серверы GigaChat используют сертификаты российского удостоверяющего центра. Если скрипт сообщает, что не удалось проверить TLS-сертификат, установите корневой (и при необходимости промежуточный) сертификат со страницы https://www.gosuslugi.ru/tls:

```powershell
Import-Certificate -FilePath .\russian_trusted_root_ca.cer -CertStoreLocation Cert:\CurrentUser\Root
```

Параметр `-SkipCertCheck` отключает проверку сертификата. Используйте его только для проверки гипотезы, не на постоянной основе.

## Использование

Запускайте скрипт из любой папки внутри репозитория:

```powershell
C:\Tools\ai-flow\ai-flow.ps1
C:\Tools\ai-flow\ai-flow.ps1 -Branch feat/home-swiper -Lang ru -Draft
C:\Tools\ai-flow\ai-flow.ps1 -DryRun
```

| Параметр | Описание |
|---|---|
| `-Branch` | Имя новой ветки. Если не указано, скрипт спросит. |
| `-Base` | Базовая ветка для pull request. По умолчанию определяется автоматически. |
| `-Remote` | Удалённый репозиторий. По умолчанию `origin`. |
| `-Model` | Модель для сообщений коммитов. По умолчанию `GigaChat-2`. |
| `-PrModel` | Модель для описания pull request. По умолчанию `GigaChat-2-Pro`. |
| `-Lang` | Язык тем коммитов и описания PR: `en` (по умолчанию) или `ru`. |
| `-MaxCodeGroups` | Максимум групп для исходного кода. Мелкие группы объединяются. |
| `-MaxDiffChars` | Размер diff, передаваемого модели для одной группы. |
| `-NoPush` | Не отправлять ветку (pull request тоже не создаётся). |
| `-NoPr` | Не создавать pull request. |
| `-Draft` | Создать pull request как черновик. |
| `-DryRun` | Показать план без изменений в репозитории. |
| `-Yes` | Не запрашивать подтверждение. |
| `-SkipCertCheck` | Отключить проверку TLS-сертификатов (небезопасно). |
| `-NoProxy` | Игнорировать системный прокси (помогает, если после VPN остался прокси в настройках Windows). |

## Правила группировки

| Группа | Файлы | Префикс коммита |
|---|---|---|
| Зависимости | `package.json`, lock-файлы, `requirements.txt`, `*.csproj` и аналоги | `build(deps)` |
| CI и контейнеры | `.github/`, `Dockerfile`, `docker-compose*` | `ci` |
| Конфигурация | `*.config.*`, `tsconfig*.json`, `.eslintrc*`, `.gitignore` | `chore(config)` |
| Ресурсы | изображения, шрифты, медиа | `chore(assets)` |
| Исходный код | остальное, по каталогам верхнего уровня | `feat`, `fix`, `refactor`, `perf` (выбирает модель) |
| Стили | `*.css`, `*.scss`, `*.less` | `style` |
| Тесты | `*.test.*`, `*.spec.*`, `tests/` | `test` |
| Документация | `*.md`, `docs/` | `docs` |

Правила находятся в функции `Get-FileCategory` и легко расширяются под ваш проект.

## Важно

- Перед формированием плана скрипт выполняет `git reset`, то есть сбрасывает индекс (рабочие файлы не затрагиваются), чтобы собрать коммиты с нуля.
- Отправка выполняется обычным `git push -u`, без `--force`.
- Для бесплатного тарифа GigaChat генерация идёт в один поток, поэтому запросы выполняются последовательно, а при ответе 429 скрипт повторяет попытку.
- Содержимое diff отправляется во внешний сервис. Не используйте скрипт для репозиториев с конфиденциальным кодом, если это недопустимо.
