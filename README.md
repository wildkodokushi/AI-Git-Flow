# 🤖 AI Git Flow (PowerShell)

Умный ассистент для Git, который работает **полностью локально**. Он использует нейросети (через Ollama) для того, чтобы автоматически разбивать ваши изменения на логические коммиты, создавать ветки и пушить их.

Больше никаких `git add .` и одного огромного коммита "fix".

## ✨ Возможности
- Создает ветку по вашему названию (например, `feat/new-header`).
- Анализирует все измененные файлы.
- Группирует файлы по смыслу (например, отдельно зависимости, отдельно стили, отдельно компоненты).
- Генерирует сообщения в формате [Conventional Commits](https://www.conventionalcommits.org/).
- Делает несколько коммитов и запушивает ветку.

## 🛠️ Требования
- Windows (PowerShell)
- Установленный [Git](https://git-scm.com/)
- Установленный [Ollama](https://ollama.com/)
- Скачанная модель (рекомендуется): `ollama run qwen2.5-coder:1.5b`

## 🚀 Установка и использование
1. Скачайте файл `ai-flow.ps1` из этого репозитория.
2. Положите его в корень вашего Git-проекта.
3. Откройте PowerShell в папке проекта.
4. Разрешите выполнение скриптов на один раз:
